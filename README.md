# Glow Beauty — Audrey, maquilleuse professionnelle

Site vitrine d'**Audrey**, maquilleuse : présentation, looks signature (photos et vidéos), prise de rendez-vous et contact.

## Contenu

- `index.html`, `style.css`, `script.js` : page d'accueil
- `B-Audrey.html`, `B-Audrey.css`, `B-Audrey.js` : seconde version de la page
- `firebase-config.js` : configuration Firebase utilisée par le site
- Images et vidéos des réalisations

## Lancer

Ouvrir `index.html` dans un navigateur, ou publier le dossier sur un hébergement statique.
